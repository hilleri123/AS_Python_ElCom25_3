# Инструкция по сдаче

1. Откройте **репозиторий своей группы** (этот), не базовый `AS_Python`.
2. Нажмите **Fork**.
   ![Как сделать форк](https://github.com/user-attachments/assets/bc11a729-4373-46e5-ac91-55daced4c430)
3. Склонируйте **свой** форк (не этот родительский репозиторий).
4. Заполните `student.json`:

```json
{
    "name_f": "Иванов",
    "name_i": "Иван",
    "name_o": "Иванович",
    "group": "ЭлКом25-3",
    "id": "222222",
    "variant": "1"
}
```

Номер варианта: `(номер зачётной книжки % 4) + 1`. Группа в файле — `ЭлКом25-3`.

5. Пишите код и **тесты** в `1lab/`, `2lab/`, `3lab/`, `4lab/`. Точка входа — `main.py`, тесты — `test_main.py`.
6. Запуск **из корня** репозитория:

```bash
python3 1lab/main.py
pytest
```

`pytest` должен проходить. Без своих тестов лабораторная не принимается.

7. Зависимости укажите в `requirements.txt` (`pytest` уже есть).
8. Закоммитьте и отправьте в `master` **своего** форка. Pull request в родителя не нужен.

## Защита

На паре: отметьтесь в таблице, попросите преподавателя посмотреть работу. Защита персональная, баллы ставятся при вас. Потом баллы появляются в git — сверьте; если ошибка, скажите сразу.

## Важно

- Если в git есть файл `.env`, работа **не смотрится**. Это ломает скрипты проверки. Удалите `.env` из репозитория (он уже в `.gitignore`).
- Проверяется взаимный плагиат. Больше 70% — работа не принимается.
- Больше 95% — работа аннулируется и больше не принимается; баллы только после дополнительного задания.
- Если списано у нескольких — баллы никому или только автору более раннего коммита.
- Не запускается `python3 Nlab/main.py` или падает `pytest` — не принимается.
- Не работает на другой ОС: **-50%**.
- Зашитые пути, которые ломают чужую машину: **-50%**.
- Больше 10 нарушений PEP 8: **-10%**.
- Падение программы: **-30%** за сценарий.
- Ввод, от которого программа падает: **-20%**.

Работу выполняйте самостоятельно.
